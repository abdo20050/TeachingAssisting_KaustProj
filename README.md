# TeachingAssisting_KaustProj
Project of using AI in education applications

## Installation & Running
First clone the repo
```bash
git clone https://github.com/abdo20050/
cd TeachingAssisting_KaustProj
```
### create conda env
```bash
conda env create -f environment.yml
conda activate myenv
```
### Run the Demo!

```bash
python ./App/app.py
```
After few minutes it will show you link to local gradio web-app click it to run the Demo!
